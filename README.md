# Radio Việt Nam Android 6 — v3.16

## Thay đổi trong v3.16
- Ô tìm kiếm trên trang chính dùng danh sách gợi ý thả xuống ngay bên dưới ô nhập.
- Gợi ý lọc theo chuỗi con, không chỉ theo ký tự đầu tên kênh.
- Chọn một gợi ý sẽ mở/phát kênh tương ứng, cập nhật khung kênh đang chọn và ẩn bàn phím.
- Khi danh sách kênh được cập nhật từ API, danh sách gợi ý cũng được cập nhật.

Build bằng GitHub Actions như các phiên bản trước. Mã nguồn chưa được build hoặc kiểm thử trên thiết bị Android thật trong môi trường này.
